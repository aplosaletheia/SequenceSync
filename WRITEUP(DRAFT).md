I tried to make a song recommender that analyzes the changes in the musical notes which are in the top 10 in terms of amplitudes. It is a track F (wildcard) project (in C) in which I hand wrote a Fourier transform, a wav parser and an append only binary database for which you normally use external libraries.
The idea of the project originated from me really getting into some sort of song for a few hours, but unable to find similar songs I just play that song on repeat for the few hours on and off. So I wanted to make a system that will recommend me songs that have a similar vibe to them musically. I thought that the criteria of changes in musical notes was a good criteria.
I realized that for my first hackathon and in the 72hr constraint and my not so good planning before the start, I had taken too big of a project (though I realized this on the second last day) . Due to that, I had given up on making the complete version for this hackathon (I'm working on the complete version right now, https://github.com/aplosaletheia/SequenceSync-). So I had to simplify or straight up remove a lot of features that were important.
Some of the specific problems I had faced were, 
  1. Mixing up between the array being row major and column major, this happened 2wise or thrice and would cause the program to silently crash. The prints gave the information that if I try to add the same file, then it crashes at the same number of cycles. After thinking on what could cause that and just jumping from function to function I spotted the error, and after spotting it here, i had to check the entire code for similar error (one still remained in the version I submitted).
  2. Using the hash map and hash values was new to me, I had never used it before (this is my 2nd or 3rd project ever and the biggest by a mile). It was simple but writing it took time. I had to learn what hash maps are and how I can use them in this case.

Writing the DFT was simple since I already knew the math, but this is one of the short comings of this project other than all the bugs, the DFT I wrote is very slow its O(n^2), I'm going to write an FFT in the complete version but for this time constraint it would have been better to use a FFT library.

For this incomplete project, the zero dependency did make the Fourier slower, but other than that everything was simple enough to had make only using libc.
